# TripBuddy ✈️

Collaborative group travel planning, budgeting, debt simplification, and itinerary management.

## 🚀 Quick Start

### 1. TripBuddy Web UI (React + Tailwind CSS + Vite)
The rich, interactive web UI is located in `web-ui/`.

From the project root:
```bash
# Using npm or pnpm
npm run dev
# or
pnpm dev

# Or double-click / run:
./run-web.bat
```
Then open: **http://localhost:5173**

Available commands from root:
- `npm run dev` - Start the Web UI dev server
- `npm run build:web` - Build the Web UI production bundle
- `npm run preview:web` - Preview the production build
- `npm run install:web` - Install web UI dependencies

---

### 2. TripBuddy Mobile App (Flutter)
The multi-platform Flutter app is located in `lib/`.

```bash
flutter run -d chrome
# or for Android:
flutter run -d android
```
